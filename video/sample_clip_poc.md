# Sample clip POC

`video/sample-clip-poc.png` — a single frame extracted from the rendered
`video/relight-demo.mp4` at t=0.0 s. This captures the initial Intro scene
(Scene 1) as reference.

Generated by:

```sh
ffmpeg -y -i video/relight-demo.mp4 -ss 0 -frames:v 1 -q:v 2 video/sample-clip-poc.png
```

This is a static verification that the pipeline outputs a valid first frame of
the animated demo.

## Using as a looped demo

To assemble a short looped clip from the full video (e.g. for a card or splash),
extract the desired segment and loop it with `ffmpeg`:

```sh
ffmpeg -y -i video/relight-demo.mp4 -ss 0 -t 3 \
  -c:v libx264 -preset veryfast -crf 19 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -shortest video/loop-poc.mp4
```

Notes

- Replace `-ss 0 -t 3` with the in/out times you want. The current
  `loop-poc.mp4` is the first 3 s of `relight-demo.mp4`.
- The reconstitution uses the same codec settings as the main render so the look
  is identical.
- For a perfectly seamless loop, pick segment endpoints at scene seams (scene 1
  audio ends around t=3.4 s; scene 2 starts).
