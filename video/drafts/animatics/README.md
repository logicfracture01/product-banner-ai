# Animatics

Low-resolution, timed animatic built from the storyboard + plan timing, before full-resolution motion graphics.

## Purpose

Confirm pacing, caption timing, camera moves, and SFX placement against the 60.000s / 1440-frame timeline before committing to final renders.

## Output

A timed preview (e.g. 720p or lower, a few seconds per scene stitched) with placeholder audio, reviewed against the plan's caption map and SFX table.
