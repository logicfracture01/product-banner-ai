# Storyboards

Rough storyboard frames for each scene, drawn from `video/plan.md`.

## What goes here

One file or folder per scene (e.g. `s01_from_flat_to_focused/`, `s02_open_relight/`, ...), each containing frame sketches or referenced frame images keyed to the frame ranges in the plan.

## Frame anchoring

Anchor every storyboard frame to a frame number from the plan (e.g. F0000, F0048, F0144, F0312, F0648, F1080, F1272). That keeps the storyboard aligned with the timing, caption map, and SFX map.

## Current state

Draft storyboards pending. The pixel-accurate plan already defines composition, so storyboards here are confirmation sketches, not design decisions.
