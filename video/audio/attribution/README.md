# Audio attribution

This folder holds the music track and sound effects used in the 60-second showreel, plus the license/attribution text for each.

## What to put here

- `music/` — the chosen music track file (e.g. `music/relight_showreel_track.mp3` or `.wav`) and a short `music/metadata.txt` with track title, artist, source URL, download date, license, and attribution requirement.
- `sfx/` — each sound effect file used, plus a `sfx/manifest.txt` listing file, source, license, attribution.
- `attribution/` — any required on-screen or description credit text, copied verbatim from the source license.

## Source guidance (from the plan)

Music: YouTube Audio Library (Music tab), search "ambient / minimal electronic / warm / technology". Save track name, artist, file, license + attribution. Only YouTube Audio Library sounds are known to YouTube to be copyright-safe; the library includes tracks that require CC attribution and tracks whose standard license does not. Confirm per-track.

Reference: https://support.google.com/youtube/answer/3376882?hl=en

SFX: choose from a reputable free SFX source and record license terms. Do not assume "royalty-free" means identical terms across files.

## Fallback

If no suitable track is available or license terms are unclear, commission or generate a placeholder bed and re License before public release. Never ship a track whose license you have not verified.
