# Release forms

Any real photograph used in this showreel (especially the original mug-on-wooden-desk still) must be backed by appropriate releases before public/distribution use.

## What to collect

- Photographer release / license granting the project the right to use the image in the showreel and derivative marketing.
- If any identifiable person appears, a model release.
- If any private property, artwork, or branded product is identifiable, confirm property/brand permission where applicable.
- Location release if the shoot location requires it.

## Where to store

- Keep signed releases (scans/PDFs) in this folder.
- Reference each release in `video/credits/asset_manifest.csv` against the corresponding still.

## Why this matters

Before/after continuity depends on using the same subject across shots. If you shoot the mug yourself or commission it, you control provenance. If you substitute stock, verify current license and restrictions on identifiable people/trademarks/brands before use.
